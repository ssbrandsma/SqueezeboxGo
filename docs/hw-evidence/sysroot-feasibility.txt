# Phase 2 — Jammy arm64 rootless sysroot feasibility (host-side, 2026-11-16)

Recipe owner: diag/jammy-build, merged as build/toolchain/jammy-sysroot.sh.
This is an INDEPENDENT feasibility re-run of its fetch+extract core only.
No payload rebuild (forbidden for this agent; tarball already exists).

## Host prerequisites used

curl, dpkg-deb, sha256sum (all present). No aarch64 cross-gcc on this
host, so the recipe's `--check` compile step was NOT re-run here
(diag/jammy-build proved it; lead verified the tarball GLIBC<=2.34).

## Exact commands

rm -rf /tmp/hw-sysroot-check && mkdir -p /tmp/hw-sysroot-check/.debs
cd /tmp/hw-sysroot-check/.debs
B=http://ports.ubuntu.com/ubuntu-ports
for f in \
  pool/main/g/glibc/libc6_2.35-0ubuntu3.18_arm64.deb \
  pool/main/g/glibc/libc6-dev_2.35-0ubuntu3.18_arm64.deb \
  pool/main/l/linux/linux-libc-dev_5.15.0-203.213_arm64.deb \
  pool/main/a/alsa-lib/libasound2_1.2.6.1-1ubuntu1.2_arm64.deb \
  pool/main/a/alsa-lib/libasound2-dev_1.2.6.1-1ubuntu1.2_arm64.deb ; do
  curl -sS --fail --max-time 120 -O $B/$f
done
sha256sum -c <pins-from-jammy-sysroot.sh>   # all 5 lines
for d in .debs/*.deb; do dpkg-deb -x $d .; done
